数据模型与权限边界

每项资源先确定空间归属，再确定所有者与可见范围；数据库查询和 API 都强制携带 scope。

核心实体关系

User 用户

账号、全局管理员标记、个人偏好、钱包；注册后自动创建个人空间。

Space 空间

类型：personal / classroom。所有教材、知识库、笔记、题库都必须属于一个空间。

Classroom 班级

绑定一个班级空间；邀请码、自定义教师/学生名称、创建者。

Membership 成员

user + classroom + role（teacher/student）+ 状态；创建者单独标记。

KnowledgeBase

空间内可有多个知识库；记录解析/OCR/Embedding/索引版本。

Resource 资料

原件、页、附件、解析结果、上传者、审核状态、内容哈希。

KnowledgeNode

概念、章节、题型、笔记、错题、题目；含来源和生成状态。

KnowledgeEdge

先修、属于、相似、解释、来源、双向链接等有类型关系。

Chunk / Vector

页码、边界框、图像锚点、全文索引和向量；绑定索引版本。

Citation 引用

回答片段 → 文档页/文本块/图像区域，支持回看和证据审计。

Conversation / Turn

即使发生在班级空间，也属于具体用户；可引用班级资源但不自动共享。

LearningMemory

L0-L3、用户、学科、证据、置信度、有效期与可见范围。

Submission / Review

学生个人资料 → 班级共享申请；保留原件引用，不移动或夺走所有权。

Ledger / Usage

充值、预留、结算、退款、Token 用量、价格与汇率快照。

关键不变量：共享不是“搬走资料”。学生原始资料仍归个人空间；教师批准后，班级空间创建一个受控共享副本/引用及独立索引。以后撤销共享，不会删除学生个人资料。

四层数据可见范围

Private · 私人

个人资料、对话、错题、学习记忆、余额。只有本人和必要的系统服务可访问。

Classroom · 班级共享

已批准资料、教师发布内容、共享知识图谱与题库。仅有效班级成员可访问。

Teacher-only · 教师管理

审核队列、成员操作、邀请码、发布历史。创建者和教师可访问。

Platform-admin · 平台运维

供应商配置状态、价格、充值、用量和故障审计；默认不浏览用户正文。

强制安全规则

服务端鉴权

前端隐藏按钮不算权限；每个 API 和 Worker 任务重新验证用户、空间和资源范围。

对象存储隔离

文件键包含空间/资源 UUID，通过短时签名 URL 访问，禁止公开永久 URL。

不可变审计

角色变更、审核、发布、撤回、充值和手工调账写入追加式审计日志。

删除语义

普通删除先软删除并停止召回；到期后后台清除原件、索引、派生数据和记忆引用。
