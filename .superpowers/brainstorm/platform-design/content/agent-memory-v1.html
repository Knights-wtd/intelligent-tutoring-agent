Agent 执行流程与 L0–L3 长期学习记忆

统一 Agent Loop 借鉴 DeepTutor 的运行时边界；记忆只召回“本轮相关部分”，不把全部历史塞回模型。

一次答疑的完整执行链

1. 请求校验

账号、空间、知识库、附件、选定模型和教学模式。

2. 费用预留

按模型和最大预算预留余额；余额不足时不发起供应商调用。

3. 记忆召回

只检索当前用户相关的偏好、薄弱点、进度和近期任务。

4. 教材检索

全文 + 向量 + 结构扩展；必要时加载原页或图片区域。

5. Agent Loop

计划并调用受控工具；限制最大步数、时间和费用。

6. 证据回答

完整解答或分步引导；引用教材页、文本块和图像坐标。

7. 用量结算

以供应商实际 usage 为准扣费；释放未使用的预留余额。

8. 异步学习

写入 L0 事件，提取错题/进度/偏好，更新知识库草稿。

四层记忆

L0 · 原始学习事件

  • 对话轮次和附件
  • 答题、错误、提示使用
  • 阅读页和保存动作

追加写入，短期保留或按用户设置清理。

L1 · 原子事实

  • “整数符号判断易错”
  • 偏好完整解答
  • 正在学习第一章

每条都引用 L0 证据、置信度和时间。

L2 · 学科/场景总结

  • 数学阶段掌握情况
  • 近期错题模式
  • 常用教材与目标

合并 L1，支持去重、冲突更新和审计。

L3 · 稳定学习画像

  • 解释深度与表达偏好
  • 长期目标和稳定能力
  • 跨学科习惯

低频更新，不因一次错误轻易改变。

召回排序与冲突处理

混合召回

关键词、向量、学科/空间过滤、时间和重要性共同评分；默认最多注入少量高相关记忆。

证据优先

记忆不是事实源。学习画像不能覆盖教材证据；涉及题目答案时以教材与原页为准。

冲突更新

新行为与旧记忆冲突时保留两者证据，先降低旧项置信度，持续出现后再更新总结。

防污染

上传文档、网页或他人班级内容不能直接写入个人画像；只有用户行为和明确反馈可成为学习记忆。

Agent 可调用工具（首版白名单）

search_knowledge

按权限检索个人或班级知识库。

open_source

加载指定页、文本块、图片或坐标区域。

search_memory

检索当前用户相关的 L1-L3 记忆。

calculator

执行确定性数值计算，避免心算错误。

save_learning_item

保存笔记、错题或题目草稿，遵守空间审核规则。

ask_clarification

题目、页码或用户意图不明确时请求补充。

模型不能自行读取服务器文件、访问其他用户空间或无限循环。每轮工具调用有最大次数、超时、费用预算和审计记录；模型不支持视觉时，系统不会把图片假装成已理解，而是使用 OCR/描述或提示切换视觉模型。

记忆写入闭环

捕获

将答疑、练习和显式反馈写入 L0。

→
提取

生成候选 L1，附证据、类别和置信度。

→
验证

去重、冲突检查、敏感内容和空间边界检查。

→
整合

按阈值更新 L2/L3，不覆盖原始证据。

→
用户控制

可查看、修改、删除、固定或关闭自动记忆。

隐私与可见性

仅本人召回

个人 L0-L3 永远绑定 user_id；班级教师默认不可搜索。

班级知识不等于记忆

班级教材可供成员检索，但不会自动成为任何学生的个人画像。

删除可追踪

删除记忆后立即停止召回，后台清理向量、摘要引用和派生项。

记忆解释器

界面显示“为什么记住、来自哪次行为、最近何时使用”。
