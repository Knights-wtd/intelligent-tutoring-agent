# AI 教材家教平台实施路线图

> 本项目包含多个可独立验收的子系统，因此按六个里程碑分别编写和执行详细计划。每个里程碑结束时都应得到可运行、可测试的软件，后续阶段不能绕过前一阶段的权限与账本边界。

## Milestone 1：平台基础、账号、空间与班级

交付注册登录、个人空间、班级创建、邀请码、教师/学生角色、服务端权限校验，以及已确认的 C3 可拖动工作台骨架。

该里程碑先执行平台骨架计划，再根据已落地接口编写账号/空间详细计划。

首个详细计划：`2026-08-14-platform-foundation-plan.md`

## Milestone 2：供应商配置、模型目录、钱包与人工充值

交付 `.env` 供应商配置、Provider Adapter 契约、模型启用、价格/汇率版本、余额预留、实际 usage 结算、不可变流水和管理员人工充值。

## Milestone 3：文件导入与版本化知识库

交付 PDF、DOCX、Markdown、图片和 Obsidian Vault 上传，原生解析优先、按页 OCR、原页证据、后台任务、索引签名、全文与向量混合检索。

## Milestone 4：AI 家教、引用、题库与长期记忆

交付完整解答/分步引导、可点击引用、受限 Agent 工具、题库、错题、L0-L3 记忆和用户记忆控制。

## Milestone 5：班级审核、自生长知识与关系图

交付学生冻结版本提交、教师审核、班级受控引用、AI 草稿发布、知识节点与关系图交互。

## Milestone 6：计费核验、安全、恢复与云迁移

交付跨租户安全测试、账本精度测试、任务断点恢复、备份恢复、Docker 本机端到端验收和 Linux 云迁移说明。

## 全程约束

- 每个业务改动先写失败测试，再实现最小代码。
- 每个任务形成小提交；权限和资金测试失败时不得继续发布。
- 普通用户界面不显示 OCR、Embedding、Agent 工具循环等内部流程。
- 真实 API Key 不进入仓库、浏览器、数据库明文字段或日志。
- 每个后续里程碑开始前，基于已落地代码补充对应的详细实施计划，避免提前假设尚不存在的接口。

## 设计覆盖检查
