# 知学空间浅色工作台排版设计

日期：2026-08-22  
状态：已确认视觉方向，待书面规格复核

## 目标

在不改变现有功能和三栏信息架构的前提下，将工作台从深色高密度界面调整为更清晰的浅色学习工作台。新界面使用暖白与浅灰作为主体，以柔紫和薄荷绿强调操作与状态，移除所有 emoji、字符图标和简单 SVG 装饰。

## 视觉方向

采用已确认的方案 A「暖白 + 柔紫」。

- 页面背景使用暖白，导航和次级区域使用浅灰紫，主要内容卡片使用纯白。
- 柔紫用于当前空间、当前标签、当前知识库、键盘焦点和主操作按钮。
- 薄荷绿仅表示连接成功、服务正常和资料可用，不承担普通装饰用途。
- 边框和阴影保持轻量，通过明度差建立层级，避免大面积纯白导致区域难以分辨。
- 不引入远程字体、图片资源、图标库或新的运行时依赖。

## 页面结构与排版

保留空间栏、内容树、中心工作区和上下文说明的现有结构，但重新分配视觉权重。

1. 空间栏继续展示个人空间、班级空间和账户入口，只保留文字标签与选中色块。
2. 内容树使用统一的缩进、分组标题和文本选中状态，不再使用 `◇`、`📚`、`📘` 等字符图标。
3. 中心工作区是视觉主区域。知识库标题、知识库选择、创建、文件上传和搜索按任务顺序排列，并使用独立分组卡片。
4. 右侧上下文说明保持辅助地位，使用更弱的背景和边框；窄屏时优先隐藏。
5. 顶部导航合并重复的视觉层级，缩短高度，但保留当前空间、当前位置和服务状态。
6. 底部状态栏只保留必要文本，字号不得低于 11px。

## 尺寸与间距

- 使用 8px、12px、16px、24px 的间距体系。
- 页面正文最小 13px，辅助标签最小 12px，主要标题 20px。
- 表单输入框和主要按钮桌面端最小高度 40px；窄屏触控目标最小高度 44px。
- 相邻操作控件间距至少 8px。
- 卡片圆角统一为 10–12px，输入框和按钮圆角统一为 8px。
- 中心面板拥有最大的默认宽度，左右面板保持可拖动调整。

## 组件调整

### 导航与状态

- 删除纯装饰图标和图形，只保留有明确含义的文字。
- 当前项使用柔紫浅底、深紫文字和清晰边框共同表达，不能只依赖颜色。
- 服务状态使用“服务正常”“已连接”等完整文字和薄荷绿状态底色。
- 尚未接通的原型按钮不得继续伪装成可用功能；实施阶段应明确禁用、移除或转换为静态文字。

### 知识库面板

- 标题区、知识库选择区、创建区、文件区和搜索区形成稳定的纵向节奏。
- 表单标签始终可见，不使用 placeholder 替代标签。
- 主按钮使用柔紫实底；次要按钮使用白底边框。
- 当前知识库与文件状态使用卡片和两列信息布局，窄屏改为单列。
- 空状态保留解释文字，避免出现大片无意义空白。

### 题库面板

- 与知识库面板共享相同的标题、卡片、表单、按钮和状态规范。
- 题目导航、答题区、评估结果、历史记录和待复习列表保持清晰分区。
- 正确、待复习和错误状态同时使用文字与色彩表达。

## 响应式行为

- 1440px 及以上：完整展示空间栏、内容树、中心工作区和右侧说明。
- 1024–1439px：缩窄空间栏和内容树，右侧说明保持较窄宽度，中心工作区优先获得空间。
- 768–1023px：隐藏右侧说明栏，保留空间栏、内容树和中心工作区，不产生页面级横向滚动。
- 小于 768px：空间栏压缩为文字短标签，内容树可折叠；中心表单和信息卡片改为单列，触控目标提升至 44px。
- 移除现有 `.panelGroup` 的固定 `min-width: 900px`，任何断点都不得依赖横向滚动展示主要任务。

## 可访问性与交互

- 正文和背景对比度不低于 4.5:1。
- 所有可操作元素保留清晰的键盘焦点环。
- hover 与 focus 过渡控制在 150–200ms，并尊重 `prefers-reduced-motion`。
- 删除图标后，按钮名称和导航含义必须由可见文字完整表达。
- 已禁用控件必须同时具有视觉弱化和原生 `disabled` 状态。

## 功能边界

本次只调整布局、颜色、排版和控件表现，不改变认证、空间选择、知识库创建、资料上传、处理状态、搜索、来源预览、题库答题、复习和历史记录的数据流或 API。

工作台中尚未接通的创建班级、全局搜索、更多操作、空间设置和展开工作区不在本次功能开发范围内，但不得继续表现为可用按钮。

## 验证标准

- 在 1440px、1024px 和 768px 宽度下进行浏览器视觉检查，不出现主要内容截断或页面级横向滚动。
- 知识库创建、空库搜索、知识库/题库切换和题库空状态继续通过浏览器冒烟检查。
- 所有现有 Web 测试通过，并新增或更新布局、可访问性和 CSS Module 合同回归测试。
- ESLint、TypeScript 和 Next.js production build 通过。
- 浅色主题下检查文字、边框、焦点和状态色对比度。

## 不在范围内

- 不新增后端接口、数据库迁移或题目创作页面。
- 不实现创建班级、空间设置或全局搜索。
- 不引入暗色/浅色主题切换器。
- 不增加动画框架、图标库、远程字体或图片资产。
